# Ploopy-Classic-to-Mini-Conversion-Mod
Ploopy Classic to Mini Conversion Mod: For when you have small hands but like the Classic over the Mini

## FAQ:

1. Where is the screw hole?

> A: I didn't know how to model it into the new bottom. Have fun with your extra screw, i guess.


2. Why is it modelled like this?

> A: I don't know how to model besides the 30 day youtube lessons out there. The hole beneath the buttons is a feature, giving you a way to hang your palm on the mouse kinda. The cut-off ball holder is also a feature, giving you more access to the ball so you can manipulate it more.


3. Why did you make this?

> A: I had the classic, but the large size made it hard to use for my small hands. I chopped off the bottom and I did some editing, and voila!


4. Oh my god why the hell is the timeline like that????

> A: See Question 2


5. What's with the decision to model X?

> A: File an issue and I'll try my best to answer them


6. Which file should I use?

> A: If you want to print the thing, use the 3mf files. I recommend printing the ball holder and the wrist rest separately. If you want to edit the model directly, use the Autodesk file.
